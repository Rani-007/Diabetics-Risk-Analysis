Diabetes Risk Analysis

Diabetes Risk Analysis is a healthcare data analytics project developed using Python. The project focuses on exploring relationships between demographic, lifestyle, and health-related factors and the Diabetes Risk Score.

🎯 Objectives

Understand and clean the dataset.

Handle missing values and check for duplicate records.

Perform Exploratory Data Analysis (EDA).

Analyze relationships between important variables.

Identify patterns, correlations, and outliers.

Present insights using meaningful visualizations.

🧹 Data Preprocessing

The dataset was examined for missing values, duplicates, and data types. Missing numerical values were handled using median imputation and categorical values using mode imputation. Additional features such as Age Group and BMI Category were created for analysis.

📊 EDA & Visualizations

The project includes:

Univariate, bivariate, and multivariate analysis

Statistical summaries

Bar charts and histograms

Box plots for distribution and outlier analysis

Scatter plots for relationships

Correlation heatmap

Group-based comparisons

🧩 Problem-Solving & Updates

During the project, the visualizations were reviewed and improved to make the charts more meaningful and easier to interpret. Incorrect or less suitable charts were replaced with updated visualizations, and the analysis was refined based on the observations from the data.

🔑 Key Insights

The analysis identified observable relationships between Diabetes Risk Score and factors such as age, physical activity, fasting blood sugar, HbA1c, and BMI.

🛠️ Tools Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook
